# SLICE: board

## Purpose

Draws the compiled Tier List as a Sheet: an editable title, Lanes of Stacks and Cards (one Lane per Tier in config order, then the Unranked Lane) and a footer, plus the Series Panel and Detail Panel dialogs. It is separate so rendering stays a pure function of Tier List Data and the reader's page-only choices.

## Public API

- `App(data)`: the whole page. A `.sheet` wraps the `SheetHeader`, the `.controls` toolbar (View: the `ViewPanel` and the `theme` slice's `ThemePicker`; Export: the `export` slice's buttons, handed the sheet element), the `FilterBar` whose `Filters` it holds, the `.lanes` and the footer. It opens with the payload's Page Defaults as overridden by the address query: `resolvePageDefaults` once over `location.search` gives `defaults`, the Page Defaults one opening starts from, copied into a `view` state the `ViewPanel` changes for the session and never saves. `viewStyle(view)` draws that state as CSS custom properties on `main.board`, and `view.showCounts`, `view.showLibrary`, `view.showLabels`, `view.showCaptions`, `view.showReadCount` and `view.laneGap` are handed down. It keeps the renamed title, the theme the picker pins and the Lane labels (by Tier id, or `unranked`) for the session, so a label survives the Unranked Lane being switched off and on. Outside the sheet it mounts the `SeriesPanel` for the opened Stack and the `Detail` for the last pick.
- `SheetHeader(data, title, showCounts, showLibrary)`: the editable `h1` title (bindable, seeded from Page Defaults and mirrored to `document.title`) and a line from `headerMeta`: the book and series counts when `showCounts`, and the library name when `showLibrary`.
- `ViewPanel(view, defaults)`: the View Panel, a "Customize view" button with a popover (`div[role="dialog"]`, "Customize view") of the Page Defaults, as `fieldset` sections: Lanes (Tier labels, Tier descriptions, Unranked lane, Empty message Shown/Hidden, Lane gap), Covers (Captions, Read count, Cover size, Cover gap) and Page (Page width, Counts, Library name). `view` is bindable; "Reset to page defaults" copies `defaults` back. Escape or a click outside closes it and returns focus to the button. Nothing it sets is saved, and it lives inside `.controls` so the export leaves it out.
- `Switch(label, on)`: a `role="switch"` button with `aria-checked` bound to `on`; its visible label toggles it too.
- `Segmented(label, options, value)`: a compact `role="group"` named `label` of `aria-pressed` buttons, one per `{ value, label }` option; `value` is bindable, and `onpick` also hands the picked value up.
- `resolvePageDefaults(baked, search) -> PageDefaults`: the Page Defaults one opening uses, from the address query: `theme`, `title`, `unranked`, `unranked_label`, `counts`, `library`, `width`, `labels`, `descriptions`, `lane_gap`, `empty`, `empty_text`, `captions`, `read_count`, `cover_size` and `cover_gap` override their field, taking the last of repeated keys; a query value wins over the baked value, which wins over the built-in default; unknown keys and invalid values are ignored for that key only.
- `viewStyle(view) -> string` / `emptyMessage(view) -> string | null` / `EMPTY_LANE_TEXT`: the inline CSS custom properties the board draws at (`--page-width`, `--cover-scale`, `--cover-gap-x/y`, `--lane-gap`), the Empty Lane Message a Lane shows or null when it is hidden, and the built-in text.
- `shownLanes(lanes, showUnranked) -> Lane[]` / `boardLanes(lanes, tiers, labels, view) -> BoardLane[]`: every Lane (or every Lane but the Unranked one), and each drawn Lane's id, payload, shown label, Tier colour and the Tier description when Tier descriptions are on and the Tier has one (never for the Unranked Lane).
- `headerMeta(bookCount, seriesCount, libraryName, showCounts, showLibrary) -> string` / `footerMeta(libraryName, showLibrary, compiled) -> string`: the meta line above the board and the footer's left part, each dropping the parts the reader turned off.
- `Lane(lane, label, colour, description, emptyMessage, showLabel, showCaption, showReadCount, books, covers, series, filters, onopen, onrename)`: one Lane as a `section` whose `aria-label` is the shown label and whose `data-lane-id` is the Tier id or `unranked`. A full-height label cell in the Tier colour holds the editable `h2` (smaller when longer than three characters, left out when `showLabel` is off) and the Tier `description` under it; with neither it stays a plain colour band at the same width. It draws `laneEntries`, so its Stacks and Cards stay interleaved in Lane Order. Only Cards whose book `matchesBook` and Stacks whose series `matchesSeries` (over the series' books) are drawn; the Lane itself stays even when empty, showing `emptyMessage` when it is not null.
- `laneEntries(lane, books, covers, series, filters) -> LaneEntry[]`: the Lane's items that survive the Board Filter, in Lane Order; each `LaneEntry` is a `stack` with its name and `Series`, or a `card` with its id, `Book` and cover. References the payload does not hold are skipped.
- `Stack(name, series, showCaption, showReadCount, books, covers, onopen)`: a `figure` named after the series carrying `data-override` when the Series Tier is an Override, with one front button, named "<series>, read of total read", that calls `onopen({ stack: name })`. The front, a Card's size, shows the cover `frontOf` picks at full colour whether or not that book is read, or the series colour, plus a `.count` "read/total" badge from `readCount` when `showReadCount` and a `.name` box when `showCaption`.
- `SeriesPanel(name, series, books, covers, tiers, onpick, onclose)`: a modal `dialog.series-panel` named after the series, with a "N of M books in your library" summary and one row per position, cut ones included; a row shows `#number`, the title or "Not in your library", and the Book Tier (or "Unranked"). Picking a row closes it and passes the `Selection` up; Escape or Close returns focus to the Stack.
- `Card(title, showCaption, cover, onopen)`: one book's cover with its title in a box over the bottom when `showCaption`; `cover` is its Cover or undefined for the Placeholder style.
- `Detail(selection, tiers, onclose)`: the Detail Panel, a modal `dialog.detail` for a `Selection` (a `Book`, or a Placeholder's series and number).
- `stack.ts`: `StackPick`, `Resolved`, `resolve(series, books, covers)` (every position with its book and cover), `frontOf(resolved)` (first owned book with a cover, else first owned book, else first position) and `readCount(resolved)` (how many owned books are read, out of how many are owned).
- `editable.ts`: `cleanText(text)` (collapses whitespace runs, trims) and the `editable(node, { value, onchange })` action: plain-text contenteditable where Enter or leaving commits the cleaned text, Escape reverts, and an empty edit falls back to the value it had.

## Files

- `SheetHeader.svelte`, `ViewPanel.svelte`, `Switch.svelte`, `Segmented.svelte`, `Lane.svelte`, `Stack.svelte`, `SeriesPanel.svelte`, `Card.svelte`, `Detail.svelte`: the components above.
- `lane.ts`: `LaneEntry` and `laneEntries`, the Board Filter applied to a Lane's interleaved items; unit tested in `lane.test.ts`.
- `page.ts`: `shownLanes`, `boardLanes`, `headerMeta` and `footerMeta`, the Lanes and meta lines the page draws; unit tested in `page.test.ts`.
- `query.ts`: `resolvePageDefaults`, the address-query overrides for Page Defaults; unit tested in `query.test.ts` and `query_view.test.ts`.
- `view.ts`: `viewStyle`, `emptyMessage` and `EMPTY_LANE_TEXT`, how the Page Defaults draw; unit tested in `view.test.ts`.
- `stack.ts`, `editable.ts`: the pure Stack helpers and the rename action, unit tested in `stack.test.ts` and `editable.test.ts`.

## Depends on

- Ports: none; it draws the Tier List Data passed as props.
- Slices: `contract` for `TierListData`, `PageDefaults`, `Tier`, `Lane`, `Book`, `Series`, `Position`, and `Cover` types; `filter` for the `Filters` type and its predicates (App also mounts `FilterBar`); `theme` for the colour tokens and `ThemePicker`; `export` for `ExportButton` and `PdfButton`. The `export` slice reads the `.sheet`, `.controls`, `.lanes`, Lanes' `data-lane-id` and, in `print.css`, the `.stack`, `.card`, `dialog.series-panel` and `dialog.detail` markup.
- Svelte only; no calibre or network access.
