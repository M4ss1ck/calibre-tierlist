# SLICE: contract

## Purpose

Defines Tier List Data once: the JSON schema the plugin produces and the TypeScript types the board renders. It is separate so the plugin and the board cannot drift.

## Public API

- `TierListData`, `Generated`, `PageDefaults`, `Tier`, `Lane`, `Book`, `Cover`, `Series`, `Position`: the typed shape of Tier List Data; `PageDefaults` is the theme, title, Unranked Lane label and header choices the page opens with.
- `loadTierListData(doc) -> TierListData`: reads the payload the plugin embedded in the page.

## Files

- `tierlist.ts`: the generated TypeScript types; generated by `pnpm gen:types` from `contract/tierlist.schema.json` and never hand-edited.
- `load.ts`: finds the embedded payload and parses it.

## Depends on

- Ports: none.
- Slices: none; `board` depends on this slice, not the other way round.
- The browser DOM only.
